# Wildcats Entrenos

App web instalable (PWA) para planificar entrenos, llevar tiempos (sesión, partido con reglas FFG, intervalos) y asistencia de Wildcats Flag Football.

- Los datos y clips se guardan en el dispositivo (IndexedDB). Este repositorio solo contiene el código: no hay datos de jugadores aquí.
- Funciona sin internet una vez instalada (service worker).
- Instalar en iPhone: abrir el enlace de GitHub Pages en Safari › Compartir › Agregar a pantalla de inicio.

Al publicar cambios, subir la versión `V` en `sw.js` para que los teléfonos descarguen la actualización.
